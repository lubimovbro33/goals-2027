# 2027 — самый яркий и самый богатый год

Трекер целей на 2027 год: 50 целей с визуализацией из Pinterest.

Сайт: https://lubimovbro33.github.io/goals-2027/

- `data.js` — цели, сферы и список картинок с доски.
- `app.js` — логика страницы (фильтры, карточки, статусы).
- Статусы «в работе» и «сбылось» хранятся в браузере.
